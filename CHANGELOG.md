# CHANGELOG
### 5.3

* The first major release
* Support for the following C++23 library features
    * `mdspan` ([P0009R18](https://wg21.link/P0009R18))
    * `extents`, `dextents` ([P0009R18](https://wg21.link/P0009R18))
    * `layout_left`, `layout_right`, `layout_stride` ([P0009R18](https://wg21.link/P0009R18))
    * `default_accessor` ([P0009R18](https://wg21.link/P0009R18))
* Support for the following C++26 library features
    * `submdspan` ([P2630R4](https://wg21.link/P2630R4))
    * `dims` ([P2389R2](https://wg21.link/P2389R2))
    * `layout_left_padded`, `layout_right_padded` ([P2642R6](https://wg21.link/P2642R6))
    * `mdspan::at()` ([P3383R3](https://wg21.link/P3383R3))
* Support for the following proposed standardization features in the Experimental namespace:
    * `mdarray` ([P1684](https://wg21.link/p1684))
